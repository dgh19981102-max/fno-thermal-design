# 神经算子代理模型用于散热设计：哪些有效，哪些无效

本项目在二维稳态热传导问题上，对比傅里叶神经算子（FNO）、U-Net 和 DeepONet 三种代理模型，并如实检验了"用代理模型做材料布局优化"这件事的效果。代理模型给出的每一个设计，都用经过验证的有限体积求解器重新核对。

[展示页](https://dgh19981102-max.github.io/fno-thermal-design/) · [完整结果表](results/summary/RESULTS.md) · [English](README.md) · [学习指南](LEARNING_GUIDE_zh.md)

## 主要结论

主对比实验用 5 个随机种子，消融和诊断实验用 3 个；训练在 Colab 的 Tesla T4 上完成。

1. **在训练分辨率上，U-Net 最准**：相对 L2 误差 6.1%，FNO 为 16.1%，DeepONet 为 15.4%。
2. **FNO 分辨率不变，U-Net 不行**：直接拿到 128×128 上测试，FNO 的误差保持在 15.9% 左右；U-Net 从 5.7% 升到 23.5%，最高温度误差从 4.6% 升到 55%。
3. **物理残差损失在各种数据量下都让 FNO 变好**：100 个样本时从 39.3% 降到 33.8%，300 个时从 28.8% 降到 22.8%，1200 个时从 16.3% 降到 12.9%。在 300 和 1200 个样本时，Welch t 检验 p≈0.007；由于只有 3 个种子，这个检验只作参考。
4. **FNO 训练误差 0.55%、测试误差 16%，差距很大，但缩小模型并不能解决**，缩小后反而变差（17.9%）。能改善的是提供更多信息：用问题本身严格成立的镜像对称做数据增强（降到 12.6%），或加入物理损失（降到 12.9%）。结论是：在这个问题上，FNO 的瓶颈是数据不够，而不是参数太多。
5. **直接在代理模型上优化，会被优化器"钻空子"**：对于优化出来的设计，FNO 把最高温度低估了 27%～52%；这些设计的真实最高温度，是伴随法（用求解器）优化结果的 1.9～2.6 倍。
6. **加一轮用求解器数据校正的步骤后，代理模型的预测变准了（误差在 ±8% 以内），但设计质量仍然赶不上伴随法，而且总耗时更长。**

一句话总结：在这个规模的问题上，神经算子适合做快速、不受分辨率限制的**初筛**；最终的设计决策，仍然应该交给伴随法求解器。

## 局限性

- "真值"是 64×64 网格上的离散解，它本身的最高温度离散误差约为 1%。
- 所有实验只用了一份数据集，随机种子只改变模型初始化和训练批次的顺序。
- 没有针对每个模型单独调参，所有模型都用相同的 15000 步训练预算。"镜像增强 + 物理损失 + 更多模态"的组合没有测试过。
- 问题是线性的，规模也小，直接求解和伴随梯度都很便宜。对于非线性、瞬态或三维问题，代理模型的价值可能更大，但本项目没有验证。
- 所有耗时数据只对应文中写明的硬件。在 CPU 上，代理模型并不比稀疏直接求解器快。

## 复现

```bash
pip install -r requirements.txt
python -m pytest -q                 # 23 个单元测试
cd experiments && python 01_verify_solver.py   # 依次运行 01 到 08，最后运行 07 生成图表
```

在 Colab 上运行，请使用 `notebooks/colab_run_all.ipynb`。各脚本、配置和结果的说明见英文 README；原理和实现细节见 [LEARNING_GUIDE_zh.md](LEARNING_GUIDE_zh.md)。
